# MediLink — next release

MediLink is an online appointment platform for small medical and dental clinics. Patients book, cancel and receive reminders; clinic staff manage schedules.

This repository holds a minimal version of the booking and reminder services, used by our team to run one development cycle with a managed engineering workflow.

- How we work: [CONTRIBUTING.md](CONTRIBUTING.md)
- Cycle plan: [DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md)
- Board: see the **Projects** tab
